# Compiler Design

This repository contains my implementations and coursework for **Compiler Design**, exploring the different stages involved in building a compiler, from source-level processing to target machine code generation.

The projects cover fundamental compiler construction concepts, including type checking, intermediate representations, code translation, and code generation.

## Repository Structure

Each directory contains an individual assignment or compiler component, along with its own README documenting the implementation details, design choices, and instructions for execution.

| Component         | Description                                                          |
|-------------------|----------------------------------------------------------------------|
| Macro to Mini     | Translation from macro-based source programs to MiniJava             |
| Mini to MiniIR    | Translation of MiniJava programs into an intermediate representation |
| Type Checker      | Semantic analysis and type checking                                  |
| MiniIR to MicroIR | Intermediate representation translation                              |
| Micro to MiniRA   | Translation to a register allocation representation                  |
| MiniRA to MIPS    | Target code generation for MIPS                                      |

*Refer to the README inside each directory for detailed documentation and execution instructions.*

## Concepts Explored

- Compiler front-end design
- Lexical and syntactic processing
- Semantic analysis and type checking
- Intermediate representations (IR)
- Code translation and generation
- Register allocation
- Target architecture and MIPS assembly

## Technologies

Java · Python · MIPS Assembly
